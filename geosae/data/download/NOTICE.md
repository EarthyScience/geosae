# Third-party code

`geosae/data/download/grid.py` adapts the MajorTOM grid arithmetic (row latitudes, per-row column
counts, column longitudes, cell centres and cell names) from
[`eodata`](https://github.com/EarthyScience/eodata) (`eodata/grids/majortom.py`),
